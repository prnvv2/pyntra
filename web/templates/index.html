Set a title for the batch task queue to make it easier to find and manage later.

 

 

 
 
 
Select a role; all tasks will be executed using that role's configuration (prompt and tools).

 

 

 
 
 
Same as chat: native ReAct, Eino single-agent (ADK), or Deep / Plan-Execute / Supervisor (the last three require multi-agent enabled).

 

 

 
 
 
Manual is for one-time runs; Cron is for recurring runs. Validate tasks manually first.

 

 

 
 
 
Use standard 5-field Cron: minute hour day month weekday. Example: `0 2 * * *` runs at 02:00 daily.

 

 

 
 
Default is off. When disabled, the queue stays pending and can be started manually later.

 

 

 
 
 
Hint: Enter one task command per line; the system will execute these tasks in order. Empty lines are ignored.
